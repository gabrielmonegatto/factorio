# remotion/

Templates React/Remotion para renderização de vídeos.

## O que vai aqui
- `compositions/` — Composições por formato (narração bíblica, histórias, etc.)
- `components/` — Componentes reutilizáveis (legendas, lower-thirds, CTA)
- `Root.tsx` — Registro de todas as composições
- `package.json` — Dependências do Remotion

## Setup inicial
```bash
cd video_factory/remotion
npm install
npx remotion studio   # abre o preview visual
```
