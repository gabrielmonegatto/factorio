# Quiz SPIN: Raio-X do Preço (Método Preço Real)

## 1. Resumo da oferta
- **Modo**: híbrido-Xisto | **Avanço**: checkout com ancoragem — página de plano do Xisto; o lead recebe o "Plano de Precificação" personalizado (curso em área de membros + planilhas)
- **Oferta** (lista fechada que limita as perguntas N): (1) método de precificação por valor com plano de reajuste em degraus [ASSUMIDO], (2) Calculadora de Preço (planilha), (3) scripts de negociação ("tá caro", pedido de desconto), (4) comunidade de designers. Entrega: área de membros + planilhas.
- **Ticket**: R$197 | **Público**: designers freelancers/estúdio pequeno já atendendo clientes; qualificação leve (etapa 1 filtra "ainda não atendo clientes" para nurturing)
- **Custo da inação** (base das implicações): dinheiro deixado na mesa em cada projeto (cobra R$800 no que valia R$2.500), desconto que não reduz escopo, cliente caçador de desconto que mais dá trabalho, anos sem reajuste, teto de horas
- **Identidade visual**: padrão Xisto — clean, fotos reais de designers (nunca IA), barra de progresso, transição em toda etapa, nome chiclete "Método Preço Real" no quiz e no criativo
- **Nº de etapas**: 28 (faixa híbrido 20–35; mecanismo simples + coleta rica pra personalização e order bump)

## 3. Etapas

### FASE 1 — AVATAR / S (Situação; 4 perguntas + 1 devolutiva)

### Etapa 1 — Perfil operacional `[S]`
- **Tela**: "Como você trabalha com design hoje?"
- **Alternativas**: ( ) Freela solo ( ) CLT + freelas por fora ( ) Estúdio/agência pequena ( ) Ainda não atendo clientes
- **Função**: calibra colchetes; qualificação leve ("ainda não atendo" → fluxo de e-mail, não desqualifica na tela)
- **Serve à Cadeia**: colchetes + qualificação

### Etapa 2 — Área do design `[S]`
- **Tela**: "Qual é a sua praia principal?"
- **Alternativas**: ( ) Identidade visual/branding ( ) Social media ( ) UI/web ( ) Editorial e outros *(fotos reais de trabalhos)*
- **Função**: nomeia módulos, exemplos e bônus da página final
- **Serve à Cadeia**: colchetes / personalização da fase D

### Etapa 3 — Tempo de profissão `[S]`
- **Tela**: "Há quanto tempo você vive de design?"
- **Alternativas**: ( ) Menos de 1 ano ( ) 1–3 anos ( ) 3–5 anos ( ) 5+ anos
- **Função**: alimenta implicação "anos cobrando a mesma coisa" e a devolutiva 5
- **Serve à Cadeia**: linha 3 (implicações) + colchetes

### Etapa 4 — Como precifica hoje `[S]`
- **Tela**: "E o preço dos seus projetos, sai de onde hoje?"
- **Alternativas**: ( ) Valor por hora ( ) Pacote copiado do mercado ( ) Eu chuto e torço ( ) Tabela antiga que nunca reajustei
- **Função**: define o gap que o método preenche; nomeia o perfil da fase D
- **Serve à Cadeia**: linha 1 + perfil calculado

### Etapa 5 — Devolutiva de dopamina `[S→P]`
- **Tela**: "Anotado. Designers de [social media] com [1–3 anos] de estrada são exatamente o perfil que mais rápido corrige o preço quando troca o chute por um critério — normalmente em 30–60 dias. Tem caminho. Vamos achar o seu."
- **Função**: ensina que responder vale a pena (padrão Xisto); zero pitch/preço
- **Serve à Cadeia**: transição; usa etapas 2–3

### FASE 2 (espinha Xisto) — MOTOR P (Problema; 4 perguntas + 1 validação)

### Etapa 6 — Incômodo declarado `[P]`
- **Tela**: "Na hora de COBRAR, o que mais te incomoda?"
- **Alternativas**: ( ) Não sei calcular — chuto o número ( ) Cliente chora desconto e eu cedo ( ) Medo de subir o preço e perder o job ( ) Sinto que não posso cobrar tanto quanto os outros
- **Função**: necessidade implícita declarada; roteia qual linha aprofundar
- **Serve à Cadeia**: linhas 1–4 (as 4 opções são a coluna Problema)

### Etapa 7 — Validação de pertencimento `[P]`
- **Tela**: "[Cliente chora desconto e eu cedo] é o que 74% dos designers marcam nesse Raio-X. Não é defeito seu — é ausência de um critério que ninguém ensinou na faculdade de design."
- **Função**: alívio de pertencimento estilo Xisto (validação, NÃO solução/oferta — o desenvolvimento pesado fica pro bloco I→N)
- **Serve à Cadeia**: eco da 6

### Etapa 8 — Tentativa frustrada `[P]`
- **Tela**: "Você já tentou subir seus preços?"
- **Alternativas**: ( ) Subi, perdi cliente e voltei atrás ( ) Subo só pra cliente novo ( ) Nunca tive coragem ( ) Subi e segurou
- **Função**: histórico que a fase I precifica; desarma o "já falhei nisso"
- **Serve à Cadeia**: linha 3

### Etapa 9 — Ponto de travamento `[P]`
- **Tela**: "E na negociação, onde você trava?"
- **Alternativas**: ( ) Na hora de FALAR o número ( ) Quando pedem desconto ( ) Quando comparam com um mais barato ( ) Em justificar o valor no papel
- **Função**: direciona scripts + alimenta order bump ("justificar no papel")
- **Serve à Cadeia**: linha 2 + analytics do order bump

### Etapa 10 — Comparação incômoda `[P]`
- **Tela**: "Com que frequência você vê designer com MENOS técnica que você cobrando 2–3x mais?"
- **Alternativas**: ( ) Toda semana ( ) De vez em quando ( ) Nunca reparei
- **Função**: inveja produtiva; abre o bloco de implicação
- **Serve à Cadeia**: linha 4

### FASE 3 (espinha Xisto) — MOTOR I (Implicação; 5 etapas ACUMULANDO, sem alívio par a par — regra dura 6)

### Etapa 11 — Conta dolorosa por projeto `[I]`
- **Tela**: "Pensa no último projeto que você entregou. Se ele tivesse sido precificado por VALOR — pelo que ele gera pro cliente — quanto a mais valia?"
- **Alternativas**: ( ) Uns 30% a mais ( ) O dobro ( ) 3x ou mais ( ) Nem quero fazer essa conta

- **Serve à Cadeia**: linha 1

### Etapa 12 — Conta dolorosa anual `[I]`
- **Tela**: "Agora estica: nos últimos 12 meses, quantos projetos saíram abaixo do que valiam?"
- **Alternativas**: ( ) Quase todos ( ) Mais da metade ( ) Alguns ( ) Nem quero fazer essa conta
- **Função**: implicação: o gap vira padrão anual, não episódio
- **Serve à Cadeia**: linha 1

### Etapa 13 — Custo do desconto `[I]`
- **Tela**: "Quando você cede no desconto... o trabalho diminui junto?"
- **Alternativas**: ( ) Não — mesmo trabalho por menos ( ) Às vezes corto escopo ( ) Nunca pensei em cortar escopo

- **Serve à Cadeia**: linha 2

### Etapa 14 — Custo invisível `[I]`
- **Tela**: "E o cliente que mais chora desconto costuma ser o que mais pede alteração depois?"
- **Alternativas**: ( ) SIM, sempre ( ) Geralmente ( ) Nunca tinha reparado nisso
- **Função**: implicação que ele não tinha somado: preço baixo ATRAI o cliente mais caro de atender
- **Serve à Cadeia**: linhas 2 e 4

### Etapa 15 — Projeção de inércia `[I]`
- **Tela**: "Cobrando exatamente do jeito que você cobra hoje: onde você está daqui 12 meses?"
- **Alternativas**: ( ) No mesmo lugar, mais cansado ( ) Com mais clientes e a mesma conta no vermelho ( ) Sinceramente, não sei ( ) Não aceito esse cenário
- **Função**: fecha o bloco I no fundo — e desagua direto na fase N (regra de Quincy)
- **Serve à Cadeia**: linhas 1 e 3

## 4. Fase D detalhada — a página de plano

**Header fixa**: cupom `RAIO50` aplicado automático (animação "você ganhou 50%") + timer de 10:00 reservando o desconto + botão fixo pulsando **[GARANTIR MEU PLANO]** (mesma ação do CTA do corpo).

**Bloco 1 — Espelho da fase N** (só o que o lead MARCOU, dinâmico):
> "Pelo que VOCÊ respondeu, o que você quer é: **cobrar sem medo do número** · **a resposta pronta quando o cliente chora desconto** · **subir preço sem perder os clientes certos** · **não decidir preço sozinho nunca mais**."

**Bloco 2 — Seu Plano de Precificação** (Benefícios Tipo B; cada um com linha de origem na Cadeia; zero contagem de módulos/aulas):
- "**Sua Calculadora de Preço Real** — o orçamento dos seus projetos de [social media] sai de um cálculo, não do chute que você marcou que usa hoje." *(linha 1 ← etapas 4, 16, 17)*
- "**Seus Scripts de Negociação** — a resposta palavra por palavra pro 'tá caro' e pro pedido de desconto: exatamente onde você marcou que trava." *(linha 2 ← etapas 9, 18)*
- "**Seu Reajuste em Degraus** — o caminho de [R$500–1.500] pra faixa de [R$1.200–2.400] sem zerar a carteira, pronto até [data +60 dias]." *(linha 3 ← etapas 8, 17, 23)*
- "**Comunidade Preço Real** — designers precificando junto: decidir sozinho, que você marcou como parte do problema, acaba hoje." *(linha 4 ← etapas 17, 19)*
- Bônus nomeados POR RESPOSTA, com preço riscado (~~R$97~~ **R$0**): quem marcou "justificar o valor no papel" (9) vê "**Bônus: Roteiro da Proposta que Justifica o Preço**"; quem marcou "medo de não conseguir aplicar sozinho" (27) vê "**Bônus: Trilha Primeiros 7 Dias acompanhada na comunidade**". *(nenhum bônus sem resposta de origem)*
- Gráfico do future pacing (etapa 23) reaparece.

**Bloco 3 — Prova social**: 6–8 prints reais de designers da comunidade; antes/depois de FATURAMENTO da mesma pessoa ("cobrava R$900 → fechei R$2.400 com a Calculadora"), slider quando a plataforma permitir.

**Bloco 4 — Preço**: destaque "**menos de R$0,55 por dia**"; discreto: "R$197 à vista ou 12x de R$19,90 — ~~R$394~~ com o cupom RAIO50 aplicado". Plano ÚNICO. Garantia de 90 dias risco zero. Sem FAQ (não é recorrência).

**Bloco 5 — Checagem espelhada** (vinda da etapa 27, sem rebate): quem marcou "se funciona pra minha área" vê 1 linha: "Seu plano já saiu calibrado pra [social media] — foi a primeira coisa que você respondeu."

**Bloco 6 — O avanço** (UM avanço, proposto UMA vez, afirmando):
> "Seu plano está montado e o valor reservado segura por [timer]. O próximo passo é um só: **[COMEÇAR A COBRAR CERTO — R$197]**"

O botão fixo da header e ~2 repetições do botão no corpo são a MESMA ação com a MESMA proposta (âncoras de rolagem), nunca um segundo pedido nem CTA em cascata com copy nova.

**Order bump no checkout**: "Kit Proposta que Vende" (R$27) — destino da dor mais clicada no analytics que NÃO está na oferta principal (previsão: "justificar o valor no papel", etapa 9).

## 6. Notas de implementação
- Plataforma: InLead (padrão Xisto) → checkout Kirvano/Lastlink via webhook; cupom automático; captura integrada ao ESP/WhatsApp.
- Analytics: % por alternativa nas fases P e I (dor mais clicada fora da oferta → order bump; calibra criativos); taxa de conclusão por fase; % de cada objeção na etapa 27; conversão da página de plano.
- Iteração: queda de abandono na fase I (11–15) = implicação pesada demais ou cedo demais — testar mover a validação 7 ou suavizar a 14; conversão baixa com conclusão alta = página de plano (design) antes de copy.
